# Sources

## Source mode

`attached_files`

## Access record

For this public example, two original files are bundled in `materials/` to stand in for files a learner might attach in an Agent conversation:

- `materials/course-notes.md` — short, original notes covering the first five concepts.
- `materials/practice-data.csv` — fictional shop-order data with one duplicate row and one missing region.

These files are public-safe and contain no personal information. Actual conversation attachment persistence and visibility to a second Agent were not tested in this build; see `QA.md`.
