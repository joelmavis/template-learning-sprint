# L05 · Freezing and showing motion

- Status: completed

## Learning objectives

- Choose shutter speed for a visual intention.
- Compensate exposure after changing shutter speed.

## Learning content

Fast shutter speeds freeze motion; slow speeds allow blur. Neither is automatically better. Freeze a gesture when detail matters, or use blur when movement itself is the subject. When shutter speed becomes faster, less light reaches the sensor, so aperture or ISO may need to change.

## Practice

Create one frozen-motion frame and one intentional-motion-blur frame. State the shutter speed and compensation used.

## Learner submission

I used 1/500 s at ISO 1600 to freeze a bicycle, then 1/20 s at ISO 200 while panning for blur.

## Feedback

Both choices match the intent, and the ISO changes show exposure compensation. The panning frame still has an identifiable rider, which makes the blur purposeful.

## Adaptation

Motion control is demonstrated; continue with colour consistency.
